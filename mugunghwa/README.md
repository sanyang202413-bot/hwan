# 무궁화 꽃이 피었습니다 · 출사동이와 함께 하는 AI 모션인식 게임

![게임 소개](assets/og-image.png)

카메라 하나로 최대 5명이 함께 하는 '무궁화 꽃이 피었습니다' 게임입니다. 술래 출사동이가 돌아보는 순간 움직이면 탈락하고, 제한 시간 안에 술래 앞 통과선까지 들어오면 성공입니다. 설치 없이 브라우저에서 바로 실행됩니다.

**바로 실행: https://sanyang202413-bot.github.io/hwan/mugunghwa/**

## 주요 기능

- 손을 1초 들면 1번부터 차례로 자동 등록 (최대 5명)
- 술래 출사동이가 앞뒤로 돌아보며 "무궁화 꽃이 피었습니다" 음성 안내
- 돌아본 순간 움직인 참가자를 자동으로 탈락 판정 (쉬움 · 보통 · 엄격)
- 어린이·성인을 구분해 통과 거리를 다르게 판정 (어린이 술래 앞 2m, 성인 3m)
- 남은 시간과 참가자별 남은 거리를 화면에 크게 표시
- 명예의 전당: 게임마다 1등 기록을 저장하고 이름을 입력, 부문별 1~3위를 게임 화면에 표시
- 게임 중 언제든 리셋
- 영상은 기기 안에서만 처리하며 어디에도 전송하거나 저장하지 않음
- 한 번 실행한 기기는 이후 인터넷 없이도 실행

## 현장 준비

| 항목 | 권장 |
|---|---|
| 기기 | 노트북 + 웹캠. 화면은 스탠바이미 등 큰 화면에 HDMI 또는 무선 미러링(Windows: `Win + K`) |
| 브라우저 | 최신 Chrome 또는 Edge |
| 카메라 높이 | 약 1m (어른이 참여하면 1.2~1.3m) |
| 출발선 | 술래(카메라)에서 5m |
| 통과선 | 술래 앞 어린이 2m, 성인 3m |
| 참가자 | 최대 5명, 서로 1m 이상 간격, 가능하면 조끼 색을 서로 다르게 |

술래 앞 2m에서는 노트북 웹캠에 보이는 폭이 약 2.6m입니다. 통과선은 술래 앞에 반원 모양으로 표시하고, 참가자가 술래 쪽으로 모이며 들어오도록 안내해 주세요.

## 진행 방법

1. 주소를 열고 **카메라 허용하고 시작하기**를 누릅니다.
2. 1번 참가자부터 차례로 손을 1초간 들면 오른쪽 목록에 자동 등록됩니다. 새 참가자는 **새 참가자 구분**에서 고른 부문(어린이 또는 성인)으로 등록되고, 목록에서 선수 이름 옆 **어린이·성인**을 누르면 한 명씩 바꿀 수 있습니다.
3. 모두 출발선에 서면 **게임 시작**을 누릅니다. 3·2·1 뒤에 시작합니다.
4. 출사동이가 뒤돌아 말하는 동안 앞으로 이동하고, 돌아보면 멈춥니다.
5. 통과선 안에 들어오면 통과입니다. 게임이 끝나면 **명예의 전당** 화면에 1등 기록이 크게 나오고, 이름을 입력하면 결과 화면으로 넘어갑니다.
6. 중간에 다시 하려면 **↺ 리셋**을 누르고 "같은 참가자로 다시" 또는 "참가자 새로 등록"을 고릅니다.

## 판정 기준

**탈락**: 술래가 돌아본 뒤 유예 시간이 지나고, 몸의 움직임이 허용치를 연속으로 넘으면 탈락합니다. 움직임은 어깨너비를 기준으로 계산하므로 카메라와의 거리와 상관없이 공평합니다.

| 난이도 | 돌아본 뒤 유예 | 허용 움직임 (어깨너비 대비) | 연속 초과 프레임 |
|---|---|---|---|
| 쉬움 | 0.8초 | 50% | 8 |
| 보통 | 0.5초 | 30% | 5 |
| 엄격 | 0.3초 | 18% | 3 |

**통과**: 술래(카메라)까지 남은 거리가 **어린이 2m, 성인 3m 이내**가 된 상태로 약 0.2초(연속 5프레임) 유지되면 통과입니다. 화면 아래 카드의 큰 숫자가 술래까지 남은 거리입니다. 거리는 화면 속 어깨너비가 출발 때보다 얼마나 커졌는지로 계산합니다(어린이 2.5배, 성인 약 1.7배).

- 통과 거리 1.2m 앞까지 왔다가 화면 옆으로 벗어나 1.5초 넘게 보이지 않으면 통과로 인정합니다. 이때 통과 시각은 남은 거리를 초속 1m로 걸었다고 보고 계산합니다.
- 화면 가운데에서 사라진 경우는 다른 참가자에게 가려진 것으로 보고 통과로 치지 않습니다. 다시 보이면 그때부터 이어서 판정합니다.
- 출발선 거리, 어린이·성인 통과 거리, 허용 움직임은 진행 패널 → 세부 설정에서 바꿀 수 있습니다.

## 명예의 전당

- 게임마다 부문(어린이·성인)별 1등의 통과 시간을 저장합니다. 어린이와 성인은 통과 거리가 달라 기록을 따로 모읍니다.
- 게임이 끝나면 명예의 전당 화면에 1등 기록이 크게 나오고 이름을 입력합니다. 이름 없이 넘어가면 "익명"으로 저장됩니다.
- 게임 화면 오른쪽 위에 부문별 1~3위가 표시되고 게임마다 새 기록으로 바뀝니다. 게임이 진행되는 동안에는 참가자 표시를 가리지 않도록 1위 기록만 작게 보입니다.
- 기록은 이 기기의 브라우저에 저장됩니다. 다른 기기나 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다. 행사가 끝나면 진행 패널 → 세부 설정 → **기록 내보내기**로 엑셀에서 열리는 파일(CSV)을 받아 두세요.
- **기록 지우기**는 두 번 눌러야 실행됩니다.

## 인터넷 없이 쓰기

행사 전에 인터넷이 되는 곳에서 이 주소를 열고 **카메라 허용하고 시작하기**를 한 번 눌러 두세요. 그 기기에 AI 엔진과 인식 모델이 저장되어 이후에는 인터넷 없이도 실행됩니다. Chrome 주소창의 설치 버튼이나 휴대폰·태블릿의 "홈 화면에 추가"를 쓰면 앱처럼 전체화면으로 열립니다.

## 문제 해결

- **카메라가 켜지지 않음**: 주소창의 자물쇠(또는 카메라) 아이콘에서 카메라 권한을 허용하세요. 카메라는 `https://` 주소에서만 열립니다.
- **스마트 TV 브라우저**: TV마다 웹 카메라 지원이 달라 인식되지 않을 수 있습니다. 노트북에서 실행하고 화면만 TV로 보내는 방식을 권장합니다.
- **오류 화면의 진단 정보**: 시작 화면에 진단 정보가 나오면 그 화면을 사진으로 남겨 두세요. 원인을 찾는 데 도움이 됩니다.

## 직접 배포하기 (GitHub Pages)

1. GitHub에서 공개(Public) 저장소를 만들고 이 폴더의 파일을 모두 올립니다. 폴더째 끌어다 놓으면 하위 폴더까지 함께 올라갑니다.
2. 저장소 **Settings → Pages**에서 Source는 **Deploy from a branch**, Branch는 **main / (root)** 로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다. 이 폴더를 저장소 안의 하위 폴더에 두었다면 주소 끝에 폴더 이름을 붙입니다.

저장소 맨 위에 빈 `.nojekyll` 파일을 두면 GitHub가 파일을 가공하지 않고 그대로 공개합니다. 이미지 등을 바꿔 다시 올릴 때는 `sw.js` 맨 위의 `VERSION` 값도 바꿔 주세요. 이미 열어 본 기기에서도 새 버전으로 바뀝니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 화면과 동작 전체 |
| `sw.js` | 인터넷 없이 실행하기 위한 저장 기능 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설치 정보와 아이콘 |
| `assets/` | 출사동이 이미지, 링크 공유 미리보기 이미지 |
| `lib/mediapipe/` | AI 동작 인식 엔진 (Google MediaPipe, 원본 그대로) |
| `models/` | 인식 모델을 직접 보관할 때 쓰는 자리 (선택, 안내는 폴더 안 README) |
