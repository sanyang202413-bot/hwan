# 무궁화 꽃이 피었습니다 · 출사동이와 함께 하는 AI 모션인식 게임

![게임 소개](assets/og-image.png)

카메라 하나로 최대 5명이 함께 하는 '무궁화 꽃이 피었습니다' 게임입니다. 술래 출사동이가 돌아보는 순간 움직이면 탈락하고, 제한 시간 안에 술래 앞 통과선까지 들어오면 성공입니다. 설치 없이 브라우저에서 바로 실행됩니다.

**바로 실행: https://sanyang202413-bot.github.io/hwan/mugunghwa/**

## 주요 기능

- 출발선에서 손을 머리 위로 들면 거의 바로(약 0.4초) 1번부터 차례로 자동 등록 (최대 5명). 셋 이상 붙어 서도 가운데 사람까지 인식하고, 여러 명이 동시에 손을 들어도 차례로 등록
- 참가자 삭제: 목록의 ✕를 두 번 누르면 삭제되고 뒤 번호가 하나씩 당겨짐 (예: 1번 삭제 → 2번이 1번)
- 부정출발 판정: 손을 들어 등록한 자리를 발끝으로 기억했다가, 게임 시작 전(등록 중, 3·2·1 동안) 0.5m 넘게 앞으로 나오면 바로 탈락
- 참가자마다 옷 색(윗옷·아랫옷·다리), 머리 부분(머리카락·얼굴색·모자), 체형, 실제 키를 기억해, 동선이 엇갈리거나 결승 근처에 몰려도 번호를 그대로 유지
- 거리는 노트북 카메라 기준으로 발끝이 바닥에 닿은 위치로 재서, 같은 선에 선 사람은 키·몸집과 상관없이 같은 거리로 표시
- 술래 출사동이가 앞뒤로 돌아보며 "무궁화 꽃이 피었습니다" 음성 안내. 출사동이는 화면 왼쪽 위 남은 시간 상자 바로 오른쪽에 상자와 같은 높이로 떠 있어 참가자를 가리지 않음
- 돌아본 순간 움직인 참가자를 자동으로 탈락 판정 (쉬움 · 보통 · 엄격)
- 어린이·성인을 구분해 통과 거리를 다르게 판정 (술래 앞 어린이 1.5m, 성인 2.5m)
- 남은 시간과 참가자별 남은 거리를 화면에 크게 표시
- 명예의 전당: 게임마다 1등 기록을 이름 또는 익명으로 등록하거나 취소. 등록하면 누적 순위를 알려 주고, 누적 1~3위는 게임 화면에 표시
- 언제든 리셋 (화면 가운데 큰 창으로 확인)
- 영상은 기기 안에서만 처리하며 어디에도 전송하거나 저장하지 않음
- 한 번 실행한 기기는 이후 인터넷 없이도 실행

## 현장 준비

| 항목 | 권장 |
|---|---|
| 기기 | 노트북 + 웹캠. 화면은 스탠바이미 등 큰 화면에 HDMI 또는 무선 미러링(Windows: `Win + K`) |
| 브라우저 | 최신 Chrome 또는 Edge |
| 카메라 높이 | 약 1m (어른이 참여하면 1.2~1.3m) |
| 출발선 | 술래(카메라)에서 6m (진행 패널에서 3~6m로 조절) |
| 통과선 | 술래 앞 어린이 1.5m, 성인 2.5m |
| 참가자 | 최대 5명, 서로 50cm 이상 간격, 가능하면 서로 다른 색 옷이나 조끼 |
| 등록 | 출발선에 서서 손을 들어 등록 (등록한 자리가 부정출발 기준). 등록한 뒤에는 카메라를 움직이지 않기 |
| 화면 구도 | 출발선에 선 사람의 발끝까지 화면에 들어오게 (발끝선으로 거리를 잼) |
| 조명 | 출발선(6m)까지 밝게. 창문을 등지고 서면(역광) 인식이 떨어집니다 |

술래 앞 1.5m에서는 노트북 웹캠에 보이는 폭이 약 1.9m입니다. 통과선은 술래 앞에 반원 모양으로 표시하고, 참가자가 술래 쪽으로 모이며 들어오도록 안내해 주세요.

## 진행 방법

1. 주소를 열고 **카메라 허용하고 시작하기**를 누릅니다.
2. 참가자는 출발선에 서서 손을 머리 위로 들면 거의 바로(약 0.4초) 오른쪽 목록에 자동 등록됩니다. 머리 위 파란 게이지가 다 차면 등록입니다. 손을 든 동안 그 사람의 옷 색·체형과 서 있는 자리를 기억하므로, 출발선에서 손을 든 채 잠깐 서 있어 주세요. 여러 명이 동시에 손을 들어도 게이지가 먼저 찬 사람부터 차례로 번호를 받습니다. 새 참가자는 **새 참가자 구분**에서 고른 부문(어린이 또는 성인)으로 등록되고, 목록에서 선수 이름 옆 **어린이·성인**을 누르면 한 명씩 바꿀 수 있습니다.
3. 모두 출발선에 서면 **게임 시작**을 누릅니다. 3·2·1 뒤에 시작합니다. 등록한 뒤부터 3·2·1이 끝날 때까지 등록한 자리보다 앞으로 나오면 부정출발로 탈락합니다.
4. 출사동이가 뒤돌아 말하는 동안 앞으로 이동하고, 돌아보면 멈춥니다.
5. 통과선 안에 들어오면 통과입니다. 게임이 끝나면 **명예의 전당** 화면에 1등 기록이 크게 나오고, **이름 등록**, **익명으로 등록**, **취소** 중 하나를 누르면 결과 화면으로 넘어갑니다.
6. 중간에 다시 하려면 **↺ 리셋**을 누르고 "같은 참가자로 다시" 또는 "참가자 새로 등록"을 고릅니다. 화면 가운데 창의 바깥을 누르거나 **취소**를 누르면 그대로 계속합니다.
7. 잘못 등록된 참가자는 목록 오른쪽 **✕**를 누르고, '삭제?'로 바뀌면 한 번 더 누릅니다. 뒤 번호가 하나씩 앞으로 당겨집니다(게임 중에는 삭제할 수 없음).

## 판정 기준

**탈락**: 술래가 돌아본 뒤 유예 시간이 지나고, 몸의 움직임이 허용치를 연속으로 넘으면 탈락합니다. 움직임은 어깨너비를 기준으로 계산하므로 카메라와의 거리와 상관없이 공평합니다.

| 난이도 | 돌아본 뒤 유예 | 허용 움직임 (어깨너비 대비) | 연속 초과 프레임 |
|---|---|---|---|
| 쉬움 | 0.8초 | 50% | 8 |
| 보통 | 0.5초 | 30% | 5 |
| 엄격 | 0.3초 | 18% | 3 |

**통과**: 술래(카메라)까지 남은 거리가 **어린이 1.5m, 성인 2.5m 이내**가 된 상태로 약 0.2초(연속 5프레임) 유지되면 통과입니다. 통과 시각은 통과 거리 안에 처음 들어온 순간으로 기록합니다. 화면 아래 카드의 큰 숫자가 술래까지 남은 거리입니다.

**거리 재는 법 (발끝선)**: 카메라 앞 바닥은 멀수록 화면 위쪽에 보입니다. 그래서 발끝이 바닥에 닿은 화면 높이로 카메라까지 거리를 재며, 모든 참가자에게 같은 식을 쓰므로 같은 선에 선 사람은 키·몸집과 상관없이 같은 거리가 나옵니다. 카메라 높이·기울기는 참가자들이 출발선에서 등록하고 다가오는 동안 스스로 맞춥니다(첫 게임 처음 몇 걸음은 조금 덜 정확할 수 있음). 술래 가까이 와서 발이 화면 아래로 벗어나면, 발이 보일 때 맞춰 둔 '몸 크기 ↔ 거리' 비율로 이어서 잽니다. 몸 크기는 어깨·골반 너비와 몸통·다리 길이를 함께 봐서, 잠깐 몸이 크게 잡히거나 몸을 돌려도 통과가 멋대로 나지 않습니다. 사람이 한순간에 갈 수 없는 만큼 거리가 튀면 그 값은 버립니다.

- 통과 거리 0.5m 앞까지 왔다가 화면 옆으로 벗어나 1.5초 넘게 보이지 않으면 통과로 인정합니다. 이때 통과 시각은 남은 거리를 초속 1m로 걸었다고 보고 계산합니다.
- 화면 가운데에서 사라진 경우는 다른 참가자에게 가려진 것으로 보고 통과로 치지 않습니다. 다시 보이면 그때부터 이어서 판정합니다.
- 출발선 거리, 어린이·성인 통과 거리, 허용 움직임은 진행 패널 → 세부 설정에서 바꿀 수 있습니다.

**부정출발**: 손을 들어 등록할 때 선 자리를 발끝선 거리로 기억합니다(발이 안 보이면 몸 크기로). 게임 시작 전에 등록한 자리보다 허용 거리 넘게 앞으로 나오면 탈락입니다. 출발선 뒤에서 등록했다면 출발선까지는 나와도 됩니다.

- 기본 허용 거리는 0.5m입니다. 출발선 6m에서 등록했다면 5.5m보다 가까이 와서 0.4초 넘게 있으면 탈락합니다. 제자리에서 흔들리거나, 반 발짝 움직이거나, 몸을 돌리거나, 손을 드는 정도로는 탈락하지 않습니다.
- 등록 중: 등록을 마친 선수가 앞으로 나오면 바로 탈락합니다. 3·2·1 동안: 모든 선수를 확인하며, 출발선으로 돌아오지 않은 채 시작해도 부정출발입니다.
- '같은 참가자로 다시'를 하면 부정출발 판정이 지워지고, 선수가 등록한 자리로 돌아온 것을 확인한 뒤부터 다시 감시합니다.
- 다른 사람과 포개져 누구인지 헷갈리는 순간에는 판정하지 않습니다.
- 진행 패널 → 세부 설정에서 끄거나 허용 거리(0.3~1.5m)를 바꿀 수 있습니다.

## 참가자 추적 (번호 유지)

- 등록할 때 손을 든 동안 그 사람의 **옷 색(윗옷·아랫옷·다리), 머리 부분(머리카락·얼굴색·모자·안경), 체형(어깨너비에 대한 엉덩이 너비·몸통 길이 비율)**을 기억합니다. 등록 뒤 출발선에 서 있는 동안에도 기억을 조금씩 다듬습니다.
- 색은 화면 가로 640점 화질로 봅니다(6m 거리 어린이도 어깨너비가 약 25점). 멀리 있을 때와 가까이 왔을 때 같은 개수의 점을 고르게 골라 비교하므로 거리가 바뀌어도 같은 기준으로 비교합니다.
- **실제 키**: 발끝선 거리로 '발끝~코 높이'를 실제 길이로 바꿔 기억합니다. 옷이 비슷해도 키가 다르면 다른 사람으로 구분합니다(카메라 위치를 스스로 맞춘 뒤부터 사용).
- 다른 사람에게 일부가 가려 색이 섞여도 같은 사람을 놓치지 않도록, '이 사람이 아니다'라고 막을 때는 가장 잘 맞는 부분들만 비교합니다.
- 누구인지 헷갈리는 순간에는 화면에 번호를 띄우지 않고 흰 뼈대로만 보여 줍니다. 번호가 순간적으로 바뀌어 보이지 않습니다.
- 화면에서 앞사람과 멀리 뒷사람이 겹쳐 보이면, 가려진 뒷사람만 판정을 잠시 멈추고 앞사람은 그대로 판정합니다.
- 얼굴만으로 사람을 알아보는 '얼굴 인식'은 쓰지 않습니다. 6m 거리에서 노트북 카메라에 잡히는 얼굴은 약 25점으로 너무 작고, 5명의 동작 인식과 함께 돌리면 노트북이 느려지기 때문입니다.
- 등록하는 동안에는 아직 번호가 없는 사람도 함께 따라갑니다. 그래서 붙어 선 이웃의 뼈대가 잠깐 안 잡혀도 손 든 사람을 이웃으로 착각하지 않고, 뼈대가 잠깐 끊기거나 손 인식이 깜빡여도 게이지가 처음부터 다시 시작하지 않습니다.
- 등록 중에는 이미 등록한 사람이 비킨 자리에 다음 사람이 서도, 옷 색이 다르면 앞 번호를 물려받지 않고 새로 등록됩니다.
- AI 엔진(MediaPipe)은 사람마다 잡은 몸 영역이 많이 겹치면 한 사람으로 합칩니다. 기본 기준에서는 50cm 안팎으로 붙어 선 세 사람 중 가운데 사람이 자주 사라져서, 이 기준을 높여 붙어 선 사람도 각각 잡히게 했습니다.
- 게임 중에는 매 순간 화면 속 모든 사람을 등록된 참가자 전원과 한꺼번에 비교해, 위치·움직이던 방향·크기·옷 색·체형이 가장 잘 맞는 조합으로 번호를 붙입니다. 그래서 두 사람이 엇갈려 지나가도 번호가 서로 바뀌지 않습니다.
- 잠깐 가려졌거나 화면 밖에 나갔다 돌아와도, 기억한 특성으로 같은 번호를 다시 찾습니다. 등록하지 않은 사람(구경꾼)은 기억한 특성과 다르면 번호를 받지 않습니다.
- 두 사람이 포개져 있거나 누구인지 헷갈리는 순간에는 탈락·통과 판정을 잠시 보류합니다. 번호가 잠깐 흔들려도 엉뚱한 사람이 탈락하거나 통과하지 않습니다.
- 모두 같은 단체복을 입으면 위치와 움직임으로만 구분합니다. 가능하면 서로 다른 색 옷이나 조끼를 입히면 가장 정확합니다.

## 명예의 전당

- 게임마다 부문(어린이·성인)별 1등의 통과 시간을 누적 기록에 남길 수 있습니다. 어린이와 성인은 통과 거리가 달라 기록을 따로 모읍니다.
- 게임이 끝나면 명예의 전당 화면에 그 게임 1등의 기록이 크게 나옵니다. 버튼을 눌러야 기록이 저장됩니다.

| 버튼 | 저장 | 표시 |
|---|---|---|
| 이름 등록 | 저장 | 입력한 이름 (최대 12자) |
| 익명으로 등록 | 저장 | "익명" |
| 취소 | 저장하지 않음 | 이번 게임 기록은 남지 않음 |

- 이름 등록이나 익명으로 등록을 누르면 **누적 몇 위인지** 크게 알려 주고, 3위 밖이면 3위 기록까지 몇 초 남았는지도 보여 줍니다. 명예의 전당 화면에서 리셋하는 경우에도 기록은 남지 않습니다.
- 게임 화면 오른쪽 위의 1~3위는 **지금까지 쌓인 모든 1등 기록 중 가장 빠른 세 기록(누적 순위)** 입니다. 그 게임의 1등이라도 누적 3위 안에 들지 못하면 화면에 오르지 않습니다. 게임이 진행되는 동안에는 참가자 표시를 가리지 않도록 누적 1위 기록만 작게 보입니다.
- 기록은 이 기기의 브라우저에 저장됩니다. 다른 기기나 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다. 행사가 끝나면 진행 패널 → 세부 설정 → **기록 내보내기**로 엑셀에서 열리는 파일(CSV)을 받아 두세요.
- **기록 지우기**는 두 번 눌러야 실행됩니다.

## 인터넷 없이 쓰기

행사 전에 인터넷이 되는 곳에서 이 주소를 열고 **카메라 허용하고 시작하기**를 한 번 눌러 두세요. 그 기기에 AI 엔진과 인식 모델이 저장되어 이후에는 인터넷 없이도 실행됩니다. Chrome 주소창의 설치 버튼이나 휴대폰·태블릿의 "홈 화면에 추가"를 쓰면 앱처럼 전체화면으로 열립니다.

## 문제 해결

- **카메라가 켜지지 않음**: 주소창의 자물쇠(또는 카메라) 아이콘에서 카메라 권한을 허용하세요. 카메라는 `https://` 주소에서만 열립니다.
- **6m 출발선에서 인식이 잘 안 됨**: 조명을 밝게 하고, 카메라가 출발선 정면을 향하게 해 주세요. 진행 패널 → 세부 설정 → 인식 모델은 **자동**(노트북·PC는 정밀 모델, 휴대폰·태블릿은 가벼운 모델)을 권장합니다. 그래도 어려우면 출발선 거리를 5m 정도로 줄이세요.
- **붙어 선 사람 중 한 명의 등록이 잘 안 됨**: 화면에 그 사람의 뼈대(흰 선)가 보이는지 먼저 확인하세요. 뼈대가 안 보이면 옆 사람과 반 발짝(20~30cm)만 벌려 서게 하세요. 뼈대는 보이는데 게이지가 안 차면 팔을 머리 위로 곧게 들게 하세요.
- **리셋 창**: 리셋 버튼은 참가자가 없을 때를 포함해 등록 중·게임 중 언제든 누를 수 있고, 확인 창이 화면 가운데에 크게 뜹니다. 터치 화면에서 두 번 눌려도 바로 닫히지 않습니다. 게임이 끝난 뒤 결과 화면에서는 그 화면의 버튼으로 다시 시작하세요.
- **거리 숫자가 이상할 때**: 출발선에 선 사람의 발끝까지 화면에 들어오는지 확인하세요. 발이 안 보이면 몸 크기로만 재서 사람마다 조금씩 다르게 나올 수 있습니다.
- **부정출발이 잘못 나왔을 때**: **↺ 리셋 → 같은 참가자로 다시**를 누르면 등록은 그대로 두고 부정출발 판정만 지워집니다. 출발선 뒤에서 등록하고 앞으로 걸어 나오면 부정출발이 되니, 등록은 출발선에서 하세요. 현장에서 자주 잘못 나오면 세부 설정에서 허용 거리를 늘리세요.
- **스마트 TV 브라우저**: TV마다 웹 카메라 지원이 달라 인식되지 않을 수 있습니다. 노트북에서 실행하고 화면만 TV로 보내는 방식을 권장합니다.
- **오류 화면의 진단 정보**: 시작 화면에 진단 정보가 나오면 그 화면을 사진으로 남겨 두세요. 원인을 찾는 데 도움이 됩니다.

## 직접 배포하기 (GitHub Pages)

1. GitHub에서 공개(Public) 저장소를 만들고 이 폴더의 파일을 모두 올립니다. 폴더째 끌어다 놓으면 하위 폴더까지 함께 올라갑니다.
2. 저장소 **Settings → Pages**에서 Source는 **Deploy from a branch**, Branch는 **main / (root)** 로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열립니다. 이 폴더를 저장소 안의 하위 폴더에 두었다면 주소 끝에 폴더 이름을 붙입니다.

저장소 맨 위에 빈 `.nojekyll` 파일을 두면 GitHub가 파일을 가공하지 않고 그대로 공개합니다. 이미지 등을 바꿔 다시 올릴 때는 `sw.js` 맨 위의 `VERSION` 값도 바꿔 주세요. 이미 열어 본 기기에서도 새 버전으로 바뀝니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 화면과 동작 전체 |
| `sw.js` | 인터넷 없이 실행하기 위한 저장 기능 |
| `manifest.webmanifest`, `icons/` | 홈 화면 앱 설치 정보와 아이콘 |
| `assets/` | 출사동이 이미지, 링크 공유 미리보기 이미지 |
| `lib/mediapipe/` | AI 동작 인식 엔진 (Google MediaPipe, 원본 그대로) |
| `models/` | 인식 모델을 직접 보관할 때 쓰는 자리 (선택, 안내는 폴더 안 README) |
